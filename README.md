## Иерархическая кластеризация, DBSCAN и оценка качества кластеризации

Занятие курса «Искусственный интеллект» для 9 класса. Ученики учатся оценивать кластеризацию без правильных ответов (коэффициент силуэта) и с ними (скорректированный индекс Рэнда). Они пишут на чистом Python агломеративную кластеризацию с тремя способами связи и метод DBSCAN, разделяют «полумесяцы», на которых ошибается метод k средних, и находят ложные отражения в облаке точек лидара беспилотного автомобиля.

## Теория (презентация)

1. **Оценка кластеризации.** Коэффициент силуэта: насколько точка ближе к своему кластеру, чем к ближайшему чужому, и выбор числа кластеров по силуэту. Скорректированный индекс Рэнда: согласие с правильными ответами по всем парам объектов с поправкой на случайность. Почему чистота растет при дроблении на мелкие кластеры, а индекс Рэнда нет.
2. **Иерархическая кластеризация.** Агломеративная кластеризация: слияние ближайших кластеров снизу вверх. Способы связи (одиночная, полная, средняя, связь Уорда), дендрограмма и выбор числа кластеров по скачку высоты слияния, эффект цепочки у одиночной связи.
3. **DBSCAN.** Кластеры как плотные области: основные, пограничные и шумовые точки, обход плотной области, подбор радиуса по графику расстояний до k-го соседа. Сравнение с методом k средних на «полумесяцах», поиск ложных отражений лидара и сбоев датчиков как шумовых точек, сравнение трех методов кластеризации.
4. **Практика.** План из семи заданий.

## Практическая работа

| Задание | Что пишем | Главный результат |
| --- | --- | --- |
| Г1 | `silhouette_samples`, `silhouette_score` | силуэт выбирает 6 объектов на парковке и 3 сорта вина |
| Г2 | `comb2`, `adjusted_rand_index` | чистота растет с числом кластеров, а индекс Рэнда нет |
| Г3 | `agglomerative` | дерево слияний на пяти точках для трех способов связи |
| Г4 | способы связи на «полумесяцах» | одиночная связь разделяет «полумесяцы» без ошибок |
| Г5 | `region_query`, `dbscan`, `point_types` | основные, пограничные и шумовые точки |
| Г6 | DBSCAN против метода k средних | «полумесяцы»: индекс Рэнда 1,000 против 0,246 |
| Г7 | `k_distances`, сцена с шумом | 32 из 40 ложных отражений лидара найдены без задания числа кластеров |

Задания повышенной сложности: поиск сбоев датчиков беспилотного автомобиля как шумовых точек DBSCAN, эффект цепочки у одиночной связи, связь Уорда своими руками, кластеры разной плотности и метод HDBSCAN, график силуэтов для набора Wine.
